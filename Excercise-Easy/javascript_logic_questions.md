10. Write a JavaScript program to check whether a number is between 1 and 100.

11. Write a JavaScript program to check whether a number is divisible by both 3 and 5.

12. Write a JavaScript program to check whether a name starts with the letter A.

13. Write a JavaScript program to check whether a customer gets a discount based on the total amount.

14. Write a JavaScript program to check the weather condition based on temperature.
