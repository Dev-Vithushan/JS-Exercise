# JavaScript Logic Practice for Beginners

This repository contains simple JavaScript logic practice questions for beginners.

Students must use these questions to improve their basic programming logic, problem-solving skills, and explanation ability.

## How This Practice Works

From tomorrow, the **StartUP Singam playlist does not need to be played during this time**.

Instead, students are requested to do this practice task and come forward to explain their solution.

Each student must explain:

- What the question is asking
- How they solved it
- The logic behind the solution
- Why they used that condition or method

## Question Order

The questions will be assigned according to the **registration order**.

For example:

- The first registered student will do **Question 1** tomorrow.
- The second registered student will do **Question 2** on the next day.
- The third registered student will do **Question 3** on the following day.

This will continue according to the registration order.

## Important Rules

1. One student needs to do only **one question per day**.
2. The student must explain the logic behind the solution.
3. The student should not just read the code.
4. The student should clearly explain how the program works step by step.
5. Everyone should listen and learn from each explanation.
6. The goal is not only to write code, but also to understand the logic.

## Purpose of This Practice

The main purpose of this activity is to help students:

- Build JavaScript logic
- Improve confidence in coding
- Learn how to explain code clearly
- Practice problem-solving step by step
- Prepare for real programming tasks

## Student Task

Each student should:

1. Check the question assigned to them.
2. Try to solve it by themselves.
3. Write the JavaScript code.
4. Understand the logic clearly.
5. Come forward and explain the solution to others.

## Note

Do not focus only on getting the correct output.

Focus on understanding the logic behind the solution.
